# Products

Each product directory is a self-contained public technical record. It should contain only documents approved for public release and must make clear whether each value is representative, example-only, or lot-specific.

## Standard product directory

```text
products/<product-slug>/
  README.md                         # Scope, grades, document index, limitations
  specifications/                   # Public product specification sheets
  coa/                              # Clearly labelled example or lot-specific COAs
  sds/                              # Current public SDS documents
  test-reports/                     # Public reports with test/method metadata
  particle-size-distribution/       # PSD datasets and interpretation notes, if relevant
  application-notes/                # Public process/application guidance
```

Use the current official product information and enquiry channel at [www.zacopper.com](https://www.zacopper.com/).
