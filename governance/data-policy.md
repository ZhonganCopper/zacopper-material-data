# Public data policy

## Scope

This repository contains technical material approved by Guixi Zhongan Copper Co., Ltd. for public release. The official company website is [www.zacopper.com](https://www.zacopper.com/).

## Required provenance labels

Every published resource must identify one of these source types:

| Source type | Meaning |
| --- | --- |
| `instrument-export` | Direct export from an instrument or its approved software. |
| `laboratory-report` | Value transcribed from an identified test report. |
| `calculated` | Value calculated from documented inputs and method. |
| `digitized-chart` | Value read/digitized from a chart; it is not an instrument-point export. |
| `representative-example` | Non-contractual example intended to show typical format or context. |
| `lot-specific` | Applicable only to an identified production lot/batch and its stated conditions. |

## Publication rules

1. Publish only approved files. Remove personal data, customer identity, confidential terms, access credentials, and unapproved internal information.
2. Preserve original units; do not silently convert or round values.
3. State limitations near the data, especially when values are representative, derived, digitized, or superseded.
4. For changes affecting technical interpretation, add a changelog entry and retain a traceable prior revision where practical.
5. Mark a resource `deprecated` instead of silently deleting it when an external citation may exist.

## Authoritative documents

This repository is a reference library. The current product-specific COA, SDS, quote, and commercial specification must be requested from [www.zacopper.com](https://www.zacopper.com/).
