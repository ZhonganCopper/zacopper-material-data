# Methods and terminology

Place public descriptions of test methods, sampling conditions, instruments, calculations, and technical terms here. A method note should name the applicable product/data files, define units, state any standards followed, and distinguish an instrument export from a derived or digitized dataset.

Method documentation explains how a value was obtained; it does not turn a representative result into a contractual specification. For current product documentation, visit [www.zacopper.com](https://www.zacopper.com/).
