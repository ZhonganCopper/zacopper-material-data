# ZA Copper 材料数据资料库

贵溪众安铜业有限公司公开发布的铜材料技术资料与结构化数据。

**官方网站：[www.zacopper.com](https://www.zacopper.com/)**<br>
如需询盘、报价、样品或当前有效的商业规格，请访问 **[www.zacopper.com](https://www.zacopper.com/)**。

本仓库不包含官网源码；它用于发布可核验、可追溯的技术资料。仓库内容不是销售合同，也不能替代针对具体批次的 COA、SDS 或书面报价。

## 资料结构

- [`products/`](products/)：按产品组织的规格、COA 示例、SDS、检测报告与应用资料。
- [`datasets/`](datasets/)：可供程序读取的 CSV/JSON 数据，并记录来源和版本。
- [`methods/`](methods/)：检测方法、采样背景、术语与指标定义。
- [`schemas/`](schemas/)：数据与文档元数据结构。
- [`templates/`](templates/)：新增产品和数据文件时必须使用的模板。
- [`governance/`](governance/)：发布、更正与版本控制规则。

## 使用前须知

请先阅读产品目录中的 `README.md`，再核查文件的来源、样品、检测方法、版本和发布日期。不同牌号、批次、检测方法及样品制备条件下的数值可能不同。除非文件明确说明，资料仅供技术参考，不构成合同规格、质量保证或合规结论。

采购、安全、工艺或合规决策，请向 **[www.zacopper.com](https://www.zacopper.com/)** 索取当前、完整且适用于具体产品/批次的文件。
